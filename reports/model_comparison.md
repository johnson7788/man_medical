## 5. 复现命令

```bash
# 1) 用训练好的 LoRA 在冻结测试集上生成（greedy，与训练同 prompt 口径）
python3 src/predict.py --model <base> --adapter <lora> \
    --ref data/ref_test.jsonl --out data/preds/<name>.jsonl
# 2) 统一对比（含 Gate 判定）
python3 src/compare_models.py --model <name>=data/preds/<name>.jsonl
```
