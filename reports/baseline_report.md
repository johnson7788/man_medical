## 解读（写进评审材料）

1. **全局常量方 = 0.159 Jaccard**。不做任何个性化已有此分，任何 Jaccard 低于 0.159 的模型都是无效的。
2. 最佳可实现基线 **B2_西医诊断检索 = 0.183**；端到端 R0 = 0.124（**低于常量方**，诊断误差代价 0.084）。
3. **Oracle 上界（诊断完全正确）= 0.208**。这是「只用离散证型标签做查表」的天花板 —— 微调模型必须突破它，
   而唯一的突破口是**从主诉/现病史自由文本里做个性化推断**，这正是本项目的核心价值主张。
4. **完全匹配率在所有基线上都是 0%**（Oracle 亦为 0%）—— 再次确认主指标必须是 Jaccard / 集合 F1。
5. 诊断侧：最佳 D2_西医诊断检索 证型 F1 = 0.368；D2 与 D1 差距很小说明西医诊断对中医证型的判别力有限。

## Gate 锚点（阈值定义与 medlib.GATES 同源）

| 指标 | 常量下界 | 最佳可实现 | Oracle 上界 | 必达 | 目标 |
|---|---|---|---|---|---|
| 处方 Jaccard | 0.159 | 0.183 | 0.208 | **>= 0.22** | >= 0.3 |
| 关键药 Recall | 0.352 | 0.378 | 0.403 | **>= 0.45** | >= 0.55 |
| 证型 micro-F1 | 0.321 | 0.368 | - | >= 0.55 | >= 0.65 |

> 两个「必达」线都设在 **Oracle 上界之上**（Jaccard 0.22 > 0.208；关键药 0.45 > 0.403）——
> 达不到就说明模型只是学会了「证型 → 常用方」的查表，没有真正读病史。
