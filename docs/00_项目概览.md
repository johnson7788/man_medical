## 1. 任务定义

**输入**：患者四诊信息（性别、年龄、主诉、现病史、西医诊断），复诊时额外给既往处方
**输出**：中医诊断（病名·证型·治法）+ 中药处方（药味，**不含剂量**）

### 输入模板（`medlib.format_input_v2`）

```
【基本信息】男，33岁
【主诉】腰痛乏力复诊
【现病史】腰痛乏力，勃起不坚，晨勃（+），手心出汗，脚凉，心悸。
【西医诊断】男性性腺功能低下
【既往处方】第 1 次复诊，间隔 9 天，上次处方：炙甘草 北柴胡 麸炒枳壳 ...
```

### 输出模板（训练目标）

```
【中医诊断】
腰痛·肾气不充证·补肾扶元
失眠·气血亏虚证·益气生脉
【中药处方】
白芍 炙甘草 桂枝 生姜 大枣 龙骨 牡蛎 茯苓 麸炒苍术 白附片 白薇 韭菜子
```

System prompt 见 `medlib.SYSTEM_PROMPT`。

### 为什么输入里要放"既往处方"

实测：复诊占 63.9%，其**最强预测因子就是上次处方**（照抄即 Jaccard 0.542），
远强于整套中医诊断（Oracle 上界仅 0.208）。不提供这个字段，
等于让医生在不知道上次开了什么的情况下开方 —— 现实中不会这样。

## 2. 三条决定性结论（先看这个）

### 2.1 处方不是证型决定的

即使把**真实**中医诊断喂给检索器（Oracle），处方 Jaccard 也只有 **0.208**。

无偏两两相似度（这才是 Oracle 上界低的根因）：

| 条件 | 两两 Jaccard |
|---|---|
| 全部随机对 | 0.075 |
| 不同证型 | 0.074 |
| 同证型 | 0.116 |
| **同病名 + 同证型** | **0.139** |

**即使病名+证型完全相同，两张处方的重合度也只有 0.139。**

### 2.2 处方是「治疗进程中的一次调整」

| 证据 | 数值 |
|---|---|
| 同一输入却有多张处方的组，来自**同一患者复诊** | **97.8%** |
| 同一患者相邻两次就诊处方 Jaccard | **0.548**（隔次及更远 0.254，随机 0.075） |
| 复诊完全不改方 | 12.7% |
| 复诊平均调方幅度 | 删 5.2 味 / 加 5.3 味 |

### 2.3 两阶段管线是陷阱

「先预测诊断 → 再用预测诊断检索处方」得 **0.124**，
**低于什么都不做的常量方 0.159** —— 诊断误差会传导放大。

**因此必须走端到端联合生成。** 修正为 T3+（含既往处方）后上界从 0.183 提到 **0.438**。

## 3. 五步推理链（架构）

```
步骤1  四诊/症状          → 证型       数据监督（同输入 87.7% 一致，可学）
步骤2  证型               → 治法       数据监督 + 确定性查表（段级 top1 85.7%）
步骤3  证型+症状+西医诊断  → 候选基础方 【检索】RAG，非生成
步骤4  候选基础方+症状     → 加减       数据监督（逐药增删）
步骤5  方中功效 ⊇ 治法     → 校验       外部中药字典，程序可校验
```

| 对应医生的思考 | 监督/校验来源 | 状态 |
|---|---|---|
| 四诊合参 → 辨证 | 数据标签 | ⚠️ 缺舌脉，有原理性上限 |
| 辨证 → 立法 | 数据标签（确定性） | ✅ |
| 依法选方 | 数据检索 | ⚠️ 天花板低（见 §3.1） |
| 随症加减 | 数据 + 症状→药关联 | ✅ 关联已挖出 |
| 配伍禁忌 | 外部中药字典 | ✅ 校验器已交付 |

### 3.1 步骤3 的天花板

| 场景 | 占比 | 基础方来源 | 强度 | 加减幅度 |
|---|---|---|---|---|
| **复诊** | 63.9% | **上次处方**（HIS 直接可取） | **0.542** | ±5 味 |
| **初诊** | 36.1% | 从输入检索 | **0.100**(top-1) | ±7.5 味 |

> **价值集中在复诊；初诊存在原理性上限。想突破只能补输入（舌脉），换算法无效。**

## 4. 技术路线

| 项 | 选择 | 理由 |
|---|---|---|
| 基座 | `XiaomiMiMo/MiMo-V2.6-Distill-Qwen-9B` | 9.4B，中文强，可单卡训 |
| 微调 | **bf16 LoRA**（非 QLoRA） | 96GB 显存下无需 4-bit 量化，更快且无精度损失 |
| LoRA | r=16, α=32, dropout=0.05 → 可训练 43.3M = 0.458% | — |
| 目标模块 | **自动探测**（12 个） | 该模型是**多模态+混合注意力**，照抄 Qwen3 名单会漏 24/32 层注意力且**静默失效** |
| 输入 | T3+（含既往处方） | 上界 0.183 → 0.438 |
| 剂量 | **模型不生成** | 原始数据 99.7% 剂量是常量 `1.000`，无信息量 |
| 安全 | 校验器后置硬拦 | 误报 5.62%，安全类检出 100% |
