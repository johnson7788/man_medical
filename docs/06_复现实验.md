# 06 · 复现实验

> 所有报告数字都能用本文的命令复现。**不需要 GPU**（除训练与推理部分）。
> 全部步骤确定性输出（`PYTHONHASHSEED` 无关）。

---

## 0. 一键全流程

```bash
pip install -r requirements.txt
./run_stage0.sh
```

11 个步骤，约 13–19 分钟（4/5/6 步计算量较大）：

| 步骤 | 内容 | 产物 | 耗时 |
|---|---|---|---|
| 1 | 数据工程 | `data/*.jsonl` | ~1 min |
| 2 | 规则基线 + Oracle + 治疗进程 | `reports/baseline_report.md` | ~2 min |
| 3 | 泄漏消融 | `reports/leakage_report.md` | ~3 min |
| 4 | 症状→药 关联挖掘 | `reports/symptom_herb_report.md` | ~4 min |
| 5 | 处方成因归因 | `reports/attribution_report.md` | ~5 min |
| 6 | 推理链可行性 | `reports/reasoning_chain_report.md` | ~2 min |
| 7 | 外部知识库 + 治法对齐 | `reports/external_data_report.md`、`zhi_action_map_report.md` | ~1 min |
| 8 | 约束校验器 | `reports/validator_report.md` | ~1 min |
| 9 | B 组离线件 | 自检输出（约束解码 / 训练 dry-run / 剂量 / 界面 smoke） | ~1 min |
| 10 | 统一评测 | `reports/stage0_baseline.json` | ~1 min |
| 11 | 文档一致性检查 | 不通过则退出码非 0 | ~10 s |

> 第 11 步会校验叙述文档里的关键数字与生成报告是否一致。
> 若你改了代码导致指标变化，这一步会失败并列出不一致项 —— **这是刻意的**。

## 2. 训练与推理复现（需 GPU）

```bash
# 1) 下载基座（18.8GB）
python3 src/download_model.py --out models/MiMo-V2.6-Distill-Qwen-9B

# 2) 自检（必须）
python3 src/train_sft.py --model models/MiMo-V2.6-Distill-Qwen-9B --inspect
#   期望：选中 12 个 target_modules，其中 in_proj_* ×24、q_proj ×8

# 3) 冒烟（90 秒）
python3 src/train_sft.py --model models/MiMo-V2.6-Distill-Qwen-9B --quant none \
  --max-steps 20 --eval-strategy no --bs 2 --ga 1 --output-dir outputs/smoke

# 4) 正式训练（2h50m / 2 epoch）
python3 src/train_sft.py --model models/MiMo-V2.6-Distill-Qwen-9B --quant none \
  --train-file data/train_v2.jsonl --val-file data/val_v2.jsonl \
  --output-dir outputs/mimo9b-tcm-lora --epochs 2 --lr 1e-4 --bs 8 --ga 2 --no-grad-ckpt

# 5) 推理（全测试集约 23 分钟）
python3 src/predict.py --model models/MiMo-V2.6-Distill-Qwen-9B \
  --adapter outputs/mimo9b-tcm-lora --ref data/ref_test.jsonl \
  --out data/preds/mine.jsonl

# 6) 评测
python3 src/compare_models.py --model mine=data/preds/mine.jsonl
```

**训练期望值**（单卡 H20 96GB）：

| 项 | 值 |
|---|---|
| 可训练参数 | 43.3M / 9.45B = 0.458% |
| 吞吐 | 2.572 samples/s |
| 2 epoch 总时长 | 2h50m |
| 每 epoch 评测（400 样本） | 约 5–7 分钟 |

> ⚠️ **精确复现的边界**：即使环境一致，`torch` 的 CUDA 归约顺序、
> batch 大小、triton 版本都会带来数值差异，个别样本的 argmax 可能翻转。
> 期望指标落在此范围即可：总体 Jaccard **0.42 ± 0.02**。

## 3. 确定性说明

本项目对确定性做过专门处理：

| 措施 | 原因 |
|---|---|
| `Counter.most_common` 换成 `sorted(key=(-count, name))` | `most_common` 的并列顺序依赖 `PYTHONHASHSEED`（实测"显著关联数"在 12/13 之间漂移） |
| 药名白名单排序固定 | `sorted(herbs, key=len, reverse=True)` 用于正则交替式 |
| 抽样固定种子 | `--sample-seed`、`random.Random(cfg["seed"])` |
| 生成用 greedy | `do_sample=False` |

**验证确定性**：

```bash
for seed in 0 1 2; do
  PYTHONHASHSEED=$seed python3 src/mine_symptom_herb.py > /tmp/mh_$seed.txt 2>&1
done
diff /tmp/mh_0.txt /tmp/mh_1.txt && diff /tmp/mh_1.txt /tmp/mh_2.txt \
  && echo "DETERMINISTIC_OK"
```
