## 2. 字段说明（`data/all_records.jsonl`）

| 字段 | 类型 | 说明 |

| 标记 | 含义 |

**`FATAL_FLAGS`**（致命，进不了金标准集）：见 `medlib.FATAL_FLAGS`。

## 3. 数据集切分

### 3.1 患者分组切分（主口径）—— `split_by_patient`

| 集合 | 样本 | 患者 |
|---|---|---|
| train | 21,484 | 7,968 |
| val | 2,675 | 996 |
| test | 2,764 | 997 |

**患者零重叠**（代码 `assert` 强制）。

> ⚠️ **为什么必须按患者分组**：若按行随机切分，test 中 **77.1%** 的样本其患者已在 train 出现。
> 实测指标虚高：B2 +22.8%、O3 +34.7%、D2 证型 F1 +30.5%。
> 详见 `reports/leakage_report.md`。

### 3.2 时间外推切分 —— `split_by_time`

cutoff `2025-07-01`，train 18,547 / test 5,380，且**强制剔除训练集患者**。
用于 G5 时效漂移评估。

### 3.3 T1 辨证预热集

`train_dx_only.jsonl` 50,142 条 = 金标准 train 21,484 + 无处方记录 28,658。
无处方记录只能进 train，且其患者不得出现在 T3 的 val/test 中（避免污染）。
另有 3,010 条因患者落在 val/test 内被跳过。

## 4. 数据文件清单

| 文件 | 条数 | 说明 |
|---|---|---|
| `all_records.jsonl` | 67,073 | 全量清洗后记录（数据工程的产物） |
| `train.jsonl` / `val.jsonl` / `test.jsonl` | 21,484 / 2,675 / 2,764 | **T3**（不含既往处方）ChatML |
| `*_v2.jsonl` | 同上 | **T3+**（含既往处方）ChatML |
| `test_time.jsonl` / `test_time_v2.jsonl` | 5,380 | 时间外推 |
| `train_dx_only.jsonl` / `val_dx_only.jsonl` | 50,142 / 2,675 | T1 辨证仅诊断 |
| `ref_*.jsonl` | 同对应集合 | **评测参考**（结构化，供 `evaluate.py` 用） |
| `herb_vocab.json` | 462 味 | 药名白名单 + top100 关键药 + 频次 |

**ChatML 格式**（训练用）：

```json
{"messages": [
  {"role": "system", "content": "你是中医男科专家。..."},
  {"role": "user", "content": "【基本信息】男，33岁\n【主诉】..."},
  {"role": "assistant", "content": "【中医诊断】\n...\n【中药处方】\n..."}
]}
```

`ref_*.jsonl` 是**结构化**参考（字段同 `all_records.jsonl`），
供评测直接比对 —— 训练文件是 ChatML，评测需要原始字段，故分开存放。

## 5. 已处理的数据质量问题

| 问题 | 规模 | 处置 |
|---|---|---|
| **剂量字段全为常量** | 410,554 条剂量中 99.7% = `1.000` | **训练目标去掉剂量**；改由药典量表填充 |
| 患者级泄漏 | 79.9% 样本来自多次就诊患者 | 强制按患者分组 + assert |
| **药名脏变体** | 76 个变体，影响 **10.8%** 记录 | 归一化 + **硬断言**（不得残留数字/字母） |
| 行内诊断重复段 | 21.1% 的行 | 段级去重 |
| 女性记录 / 年龄异常 | 1,131 / 351 条 | 剔除 |
| 日期未补零 | **3,363 条**被错误分入测试集 | `pd.to_datetime().strftime('%Y-%m-%d')` + 格式断言 |

### 药名归一化的坑（留档）

早期剂量后缀正则只剥一层，`酒黄精10g1.000` → `酒黄精10g`，
把 **51 味药拆成两味**，影响 **2,900 条记录（10.8%）**。
修复后正则：`(?:\d+(?:\.\d+)?\s*(?:g|G|克|mg|ml|ML)?)+$`，药材数 512 → 462。
并加 `assert_clean_herb_name` 硬断言，防止再犯。

## 6. 诊断与处方统计

| 项 | 数值 |
|---|---|
| 病名 | 263 种 |
| 证型 | 499 种（金标准口径） |
| 治法 | 320 种 |
| 药材 | **462 味**（train 出现 454 味） |
| 平均药味数 | 14.8（p90 = 23，范围 1–81） |
| 证型组合 | 2,217 种，其中仅 57 种样本 ≥50 |
| 初诊 / 复诊 | 36.1% / **63.9%** |

### 证型标签的同义问题（重要）

参考标签中存在大量近义写法，**同一含义有多个字符串**：

| 组 | 参考中出现次数 |
|---|---|
| `肾虚证` / `肾虚` | 906 / 163 |
| `肝肾亏虚证` / `肝肾两虚证` | 428 / 289 |
| `湿热下注证` / `下焦湿热证` | 826 / 360 |

同一份预测，仅改标签口径：

| 口径 | 证型 micro-F1 |
|---|---|
| 原始 | 0.4848 |
| 仅去尾字「证」 | 0.5075 |
| 去尾字 + 同义合并 | **0.5378** |

> 同义合并表**需中医师确认**（属医学判断，不能由程序决定）。
> 详见 `reports/训练评测报告.md` §3。
