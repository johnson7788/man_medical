## 数据来源与采集

真实门诊电子病历（EMR）的结构化导出。原始表为 10 列 Excel，含：

就诊日期、性别、年龄、主诉、现病史、西医诊断、中医诊断（`病名/证型/治法`）、
中药处方（`药名1.000,药名2.000,...` 形式）、病历号、脱敏病历号。

### 已做的隐私处理

| 处理 | 说明 |
|---|---|
| 患者 ID 哈希 | `P` + 12 位 hex，25,103 个唯一值；**无原始病历号残留** |
| 机构名归一化 | 234 个院名 → 「外院」（1,716 条记录，3,959 处替换） |
| PHI 扫描 | 手机号 / 身份证 / 座机 / 社交账号 **命中 0** |

### 未做的处理（须使用者知悉）

| 项 | 状态 |
|---|---|
| **伦理审查（IRB）** | ❌ **未做** |
| **患者知情同意** | ❌ **未做** |
| 就诊日期平移 | ❌ 未做（保留完整时间信息以支持时效性评估） |
| 舌象/脉象 | ⚠️ 原始数据即缺失（舌 0.53% / 脉 0.74%） |

## 切分方案

**按患者分组**（GroupShuffleSplit by `pid`），保证**患者零重叠**：

| 集合 | 样本 | 患者 |
|---|---|---|
| train | 21,484 | 7,968 |
| val | 2,675 | 996 |
| test | 2,764 | 997 |

时间外推集：cutoff `2025-07-01`，train 18,547 / test 5,380，且强制剔除训练集患者。

> ⚠️ **不要按行随机切分**。实测那样 test 中 77.1% 的样本患者已在 train 出现，
> 会让基线指标虚高 **+22.8% ~ +34.7%**。

## 统计

| 项 | 数值 |
|---|---|
| 病名 | 263 种 |
| 证型 | 499 种 |
| 治法 | 320 种 |
| 药材 | **462 味** |
| 平均药味数 | 14.8（p90 = 23，范围 1–81） |
| 初诊 / 复诊 | 36.1% / **63.9%** |

### 已知的数据特点（会影响建模）

1. **剂量字段无信息量**：原始 410,554 条剂量中 99.7% 是常量 `1.000`，
   **已整体丢弃**。因此本数据集不含剂量，模型也不应生成剂量。

2. **证型标签存在同义写法**：

   | 组 | 出现次数 |
   |---|---|
   | `肾虚证` / `肾虚` | 906 / 163 |
   | `肝肾亏虚证` / `肝肾两虚证` | 428 / 289 |
   | `湿热下注证` / `下焦湿热证` | 826 / 360 |

   仅做标签同义合并即可把证型 micro-F1 从 0.485 提到 **0.538**。
   **但同义判定属医学判断，需中医师确认**，本数据集未做合并。

3. **长尾证型**：2,217 种证型组合中仅 57 种样本 ≥50。

4. **文书复制粘贴**：主诉常被直接复制为现病史开头，`flags` 里有标记。

5. **医师风格混杂**：无医生 ID，实测 13/16 组文书风格检验显著（p<0.05）。

## 使用示例

```python
import json, sys
sys.path.insert(0, "src")
import medlib as M

# 读取全量记录
recs = M.read_jsonl("data/all_records.jsonl")
print(len(recs))                    # 67073

# 只取金标准
gold = [r for r in recs if M.is_gold(r)]
print(len(gold))                    # 26923

# 构造模型输入（T3+，含既往处方）
print(M.format_input_v2(gold[0]))

# 读取训练用的 ChatML
rows = [json.loads(l) for l in open("data/train_v2.jsonl", encoding="utf-8")]
print(rows[0]["messages"][1]["content"][:200])
```
